## 2. 游戏设计（原始意图）

### 2.1 核心立意

**不是"考多少分"的游戏，而是"在制度压力下如何照顾自己和他人"的模拟。**

三方同理心视角是它最有价值的设计——同一个结局，分别从**学生 / 教师 / 家长**三个角度解读：

```
【崩溃边缘 · 三方视角】
学生：这不是意志力不够，而是能量、压力、身体需求同时越界。
教师：当一个学生突然失控时，前面通常已经有很多小动作、沉默和回避。
      提醒纪律之前，可以先判断是不是求救。
家长：如果孩子只说"没事"，可以少追问成绩，多问今天最累的时刻在哪里。
```

**这句话是写给老师看的**——这是它区别于普通学生题材作品的地方。

### 2.2 属性系统

```
能量 ←→ 压力 ←→ 暴露 ←→ 面具成本 ←→ 支持网络 ←→ 注意力
  ↑                                              ↓
身体需求（渴/饿/如厕）              制度压力（KPI/巡视/同理心）
```

设计意图是**没有无脑最优解**：

| 动作 | 收益 | 代价 |
|---|---|---|
| 写作业 | 作业 +12 | 能量 -11、压力 +5、面具 +4 |
| 看手机 | 能量 +7 | 暴露 +18~35、面具 +14 |
| 同桌 | 支持 +14 | 暴露 +7~16 |
| 观察 | 信息 | 能量 -4、暴露 +2 |

**但实测发现这个平衡被破坏了**（见第 3 节）。

### 2.3 第一章流程（当前实现）

```
序章（走廊）→ 教室观察林澈 → 定位哭声 → 调节自己
  → 接近林澈 → 检查纸条 → 跟上他 → 章末决策（4选1）→ 结算
```

固定 **6 回合**（总预算 18 回合）。

## 3. 可玩性诊断（实测数据，必读）

以下全部是**用 Agent 模式实际跑出来的数据**，不是推测。

### 3.1 致命问题：主线路径毫无紧张感

**主线最优玩法**的逐回合数值：

```
回合   能量   压力   暴露   面具   支持   注意
 1     74     38     18     22     42     84
 4     70     35     23     20     43     84   观察林澈
 7     66     32     28     18     44     84   观察哭声
 9     77     22     31     15     44    100   深呼吸
11     82     22     38      8     58    100   同桌
16     78     21     34      8     58     92   举手
```

**观察结果**：
- 能量全程**没低于 66**
- 压力**一路下降**（38 → 21）
- 暴露**从未超过 38**（危险线是 92）
- 面具**一路下降**（22 → 8）

**整局没有任何数值进入危险区。玩家从头到尾没有感到过压力。**

### 3.2 对比：乱玩时游戏立刻变紧张

**全程"看手机"**：

```
回合   能量   压力   暴露   面具
 1     74     38     18     22
 2     81     43     26     36
 3     88     67     66     50    ← 压力飙升
 4     95     91    100     64    ← 4 回合就爆
```

「被发现」触发 4 次。

### 3.3 根因分析

**根因 A：恢复动作是"纯赚"**

```
深呼吸：能量 +11、压力 -10、面具 -3    ← 全正收益，零代价
同桌：  支持 +14、能量 +5、面具 -7     ← 全正收益
观察：  压力 -3                        ← 免费信息
```

总收益 > 总消耗 → 主线必然"越玩越舒服"。

**根因 B：暴露没有梯度预警**

```
暴露 18 → 38   ← 玩家感觉不到"在冒险"
暴露 66 → 100  ← 突然就爆
```

中间缺少"老师开始注意你"的过渡反馈。

**根因 C：核心机制在主线里用不上**

`discoveryRisk > 92` 才触发"被发现"，但主线 6 回合暴露最多到 38。
**"暴露"这个核心机制在主线路径上完全失效。**

### 3.4 一句话总结

> **这游戏有紧张感，但藏在"错误玩法"里。**
> 认真跟随主线的玩家会玩到一个安全、无压力的流程；
> 只有"乱来"（刷手机、传纸条）才能触发出真实的高压体验。

**这是个反转——惩罚机制比主路径更有趣。必须修正。**

## 4. 优化路线图（按优先级）

### 4.1 🔴 P0：让主线也有代价（核心）

| 措施 | 具体改动 | 预期效果 |
|---|---|---|
| **观察不再免费** | `观察` 暴露从 +2 提到 +6，且不再降低压力 | 获取信息需要冒险 |
| **恢复有门槛** | `深呼吸` 在压力 < 30 时效果减半或失效 | 消除无脑刷 |
| **加入时间压力** | 主线每步限 5 回合，超时触发后果 | 制造紧迫感 |
| **同桌有风险** | `同桌` 暴露提高，且老师靠近时可能被记录 | 支持不是免费的 |

**验收标准**：主线最优路径下，暴露应至少达到 **60+**，能量应至少一次低于 **35**。

### 4.2 🟡 P1：让"危险"可见

玩家必须在**被抓住之前**知道自己危险。当前暴露是纯数字，需要反馈层：

```
暴露 < 30  →  "教室很安静，笔尖声清晰"
暴露 30-50 →  "有人往你这边看了一眼"
暴露 50-70 →  "老师的脚步变慢了"
暴露 > 70  →  "你感觉被盯住了，后背发紧"
```

**实现建议**：
- 文本层：在 `updatePerception()` 里加入分段提示
- **视觉层**：教师视线锥的颜色/亮度随暴露变化（`SceneRGBRenderer` 已支持点光源）
- 听觉层：心跳声频率随暴露上升（`SpatialAudioManager` 已支持）

### 4.3 🟡 P2：拉长并扩展内容

当前第一章只有 6 回合，占总预算 18 回合的 1/3。

**方案 A**：让主线贯穿全程（6 回合 → 16 回合）
**方案 B**：补齐第二~六章（参考 `freatures/tyc` 的 `NarrativeCampaign.swift`）

> `freatures/tyc` 已有完整六章设计：
> `classroom → mirror → noteTrace → stairwell → counseling → epilogue`
> 可直接移植。

### 4.4 🟢 P3：数值曲线细化

- 写作业从固定 `-11 能量` 改为**递减**（越写越累：-9/-11/-13/-15）
- 每回合加入**自然压力增长**（人不会凭空平静）
- 身体需求影响注意力（口渴/饥饿降低聚焦质量）

### 4.5 🟢 P4：3A 化提升（长期）

| 方向 | 说明 |
|---|---|
| **美术** | 当前是纯色块几何体，需要真实模型/贴图/光照 |
| **动画** | NPC 有程序化动画，但需要骨骼动画 |
| **配音** | 当前是程序化音频，3A 需要真实配音与环境音 |
| **跨平台** | iOS/iPadOS（参考 `features/ios` 分支）|
| **本地化** | 当前全是硬编码中文字符串 |

## 6. Agent 模式（你的主要工具）

这是上一位代理专门为 AI 游玩/评估构建的工具。**请务必使用它来验证你的改动。**

### 6.1 用法

```bash
# 交互式游玩
swift run LateStudySimulator --agent

# 全知视角（显示所有隐藏数值）
swift run LateStudySimulator --agent --omniscient

# 执行单条命令
swift run LateStudySimulator --agent --omniscient --command "look left"

# JSON 输出（机器可读状态）
swift run LateStudySimulator --agent --json --command "state"

# 逐像素 RGB 数据（评估画面）
swift run LateStudySimulator --agent --command "frame"

# 按剧本自动跑
swift run LateStudySimulator --agent --script play.txt

# 内置 AI 自动游玩（五种策略）
swift run LateStudySimulator --agent --auto main
swift run LateStudySimulator --agent --auto-all
```

### 6.2 可用命令

| 命令 | 说明 |
|---|---|
| `<动作名>` | 写作业/看手机/传纸条/观察/同桌/深呼吸/看窗外/喝水/吃零食/举手 |
| `look <方向>` | forward / desk / board / left / right / rear |
| `move <wasd>` | 自由活动移动 |
| `wait` | 跳过一回合 |
| `继续` / `阅读` | 章节转场 / 纸条环节 |
| `state` / `omniscient` / `frame` / `history` | 状态查询 |
| `color` / `noColor` | 开关 ANSI 真彩 |

### 6.3 五种评估策略

`--auto-all` 会跑五种策略并输出结局对比：

```
主线优先 → 让成人接手
全力学习 → 带着不确定入睡
自我照顾 → 同伴协作链
社交路线 → 留下来的人
随机游走 → （随机）
```

**用这个验证你的改动是否让不同玩法产生不同结果。**

### 6.4 渲染系统

`SceneRGBRenderer` 重建了完整光照管线：

- 材质库（`SceneMaterials`）：颜色取自真实场景定义
- 光照：环境光（随时间变化）+ 点光源（教师压力灯、手机蓝光）
- 后处理：饱和度衰减（疲劳）、暗角（压力）
- 输出：ANSI 24 位真彩字符画 + 逐像素 RGB 数据

**用途**：AI 可以评估"玩家看到的画面是否传达了正确的情绪"。

## 8. 工作约束与建议
