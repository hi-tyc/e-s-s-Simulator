# F-11 镜像空间场景

> 状态：final / accepted
> 实现阶段：Phase 3
> 依赖特性：F-04（叙事相机模式与场景呈现）

## 产品能力描述

第二章《走廊的镜子》的核心体验：玩家跟随林澈走进走廊镜面，进入冷调的"镜像空间"，在这个隐喻性空间中感受林澈内心的压力，并在三盏灯全亮后回到现实走廊完成对话选择。镜像空间为第二章三个微游戏（F-12）提供场景容器与进退出口，并通过色温翻转和空间音频区分虚实两个世界。

## 功能边界

**包含：**
- 走廊场景到镜像空间的进入与退出过渡（色温翻转动画 0.8s）
- 镜像空间节点根的显示/隐藏与灯光/材质切换
- 林澈 NPC 在镜像空间的冷调材质版本与路径动画
- 地面光路（发光贴图，从草稿灯→旋律灯→擦痕灯依次延伸）
- 三灯全亮后的镜像世界褪色过渡（10s 线性）与现实材质恢复
- 步骤 7（回到身边说真实的话）和步骤 8（问林澈愿不愿意一起找人）的对话选项与结果写入
- `Ch2State` 持久化与存档恢复（灯状态、林澈位置与对话选择）

**不包含：**
- 草稿灯、旋律灯、擦痕灯各自的微游戏 overlay 实现（属于 F-12）
- 第二章章节级 SceneDirector Beat 注册（属于 F-02 的全局职责）
- 走廊本身的场景几何构建（属于 F-04/F-06）

## 验收标准

- [ ] 玩家靠近镜面（≤ 0.8m）并按确认键后，0.8s 内完成色温翻转（暖黄→冷蓝），镜像林澈 NPC 出现，背景音切换到低频共鸣 120Hz + 钟声混响
- [ ] 三个微游戏完成后，镜像空间褪色在 10s 内线性完成，走廊现实材质恢复；林澈 NPC 在褪色前转过正脸
- [ ] 步骤 7 的对话选择正确写入 `Ch2State.returnDialogueChoice`（`.reassure/.inviteToShare/.stayPresent` 三种），步骤 8 的对话选择正确写入 `Ch2State.handoffChoice` 与 `GameNarrativeState.linCheTrust`
- [ ] 存档后恢复：已完成的灯（`completedLights`）状态、地面光路延伸位置、林澈 NPC 阶段位置与褪色进度与存档时一致，不重新触发已完成的过渡
- [ ] `activePauseReasons` 非空时，色温过渡动画和褪色进度冻结；恢复后从归一化进度继续，不重新开始
- [ ] 系统 Reduce Motion 开启时，色温翻转与褪色改为 0.2-0.4s 淡入淡出，完成判定逻辑不变

## 设计约束

- 镜像空间必须作为走廊场景中的**独立节点根**实现，通过可见性、灯光和材质切换，不得复制整个 `SCNScene`（来自 `find-help-resolve-detail.md` §E）
- `ClassroomCoordinator` 内的 `MirrorSceneNodes` 容器不持有剧情状态，只根据 `scenePresentation` 做单向映射（来自 §2.6 代码映射）
- 色温过渡使用 `SCNLight.color` 和 `SCNLight.temperature` 插值，不使用不存在的 `SCNLight.ambientColor`（来自 §2.3 步骤 2）
- 所有场景节点操作归 `ClassroomCoordinator.update(game:)` 单向映射，`SceneDirector` 不直接持有节点
- 章节切换、返回菜单或读档时必须取消本章所有 Beat 并重置节点状态
