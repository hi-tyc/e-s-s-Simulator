# F-13 引导第三人称移动与热点交互

> 状态：final / accepted
> 实现阶段：Phase 4
> 依赖特性：F-04（叙事相机模式与场景呈现）

## 产品能力描述

从第三章起，玩家以受引导的第三人称视角在教室、走廊、楼梯间自由移动，通过靠近场景中的热点并按确认键触发交互，为纸条调查、同伴选择和进入楼梯间提供空间行为基础。相机始终保持叙事意图的跟随偏移，不切换为完全自由相机。

## 功能边界

**包含：**
- `NarrativeCameraMode.guidedThirdPerson` 相机映射：固定偏移跟随玩家位置，含遮挡处理
- `PlayerAction.leaveSeat` 触发从固定座位第一人称到第三人称的过渡
- WASD 驱动的角色平面移动（复用现有移动与碰撞，不重新实现）
- 热点近距离激活（距离 ≤ 1.5m 时触发高亮与交互提示）
- 热点确认键交互，调用统一的 `completeStep` 完成步骤
- 全部热点支持键盘焦点导航（Tab 循环 + 确认键）
- 从第三人称返回第一人称对话视角（`dialogueFirstPerson`）的过渡

**不包含：**
- 同伴 NPC 跟随逻辑（属于 F-14）
- 章节内具体步骤的叙事触发（属于 F-15、F-16）
- 对话系统和信任值（属于 F-16）
- 跑步、跳跃或完全自由探索（设计意图是引导而非开放世界）
- 碰撞系统修改（复用现有实现）

## 验收标准

- [ ] `PlayerAction.leaveSeat` 执行后，`ScenePresentationState.cameraMode` 切换为 `.guidedThirdPerson`，相机在 0.4s 内平滑过渡到玩家背后固定偏移位置
- [ ] WASD 输入驱动角色移动，相机跟随偏移保持一致；移动中不出现相机穿墙或抖动
- [ ] 玩家角色距热点 ≤ 1.5m 时，热点 SCNNode 出现边缘高亮，HUD 显示确认键提示
- [ ] 玩家离开热点范围（> 1.5m）后高亮自动消失，不残留交互提示
- [ ] 按确认键触发热点交互，`GameManager.completeStep(_:result:)` 被调用一次且仅一次（幂等）
- [ ] 所有热点可通过 Tab 键切换键盘焦点，焦点可见，按 Enter/E 等效于鼠标确认
- [ ] 系统 Reduce Motion 开启时，第三人称切换过渡改为 0.3s 淡入淡出，不做推轨动画
- [ ] 章节切换或读档后，相机模式、热点激活状态与存档一致还原

## 设计约束

- 第三人称只改变相机跟随方式，不新增一套碰撞与输入系统（来自详细需求 §3.6）
- `guidedThirdPerson` 是叙事相机模式枚举的一个 case，由 `ScenePresentationState` 持有，`GameManager` 是唯一写入方，`ClassroomCoordinator` 只读取并映射（来自详细需求 §E）
- 热点确认调用 `completeStep` 必须幂等；玩家操作与 SceneDirector 兜底同时到达时只提交一次结果（来自 PRD §4.1）
- 对话阶段冻结位移但不冻结环境动画（来自详细需求 §E）
- 所有热点必须支持键盘焦点导航，不能只依赖鼠标悬停（来自 PRD §4.7）
