# F-14 同伴 NPC 系统

> 状态：final / accepted
> 实现阶段：Phase 4
> 依赖特性：F-01（叙事状态机）、F-13（引导第三人称移动与热点交互）

## 产品能力描述

玩家在第三章《那张纸条》中可以选择班长周予安或文体委员许栀作为同行者。同伴 NPC 会跟随玩家前往楼梯间，在第四章自动执行差异化的辅助行为（联络方老师方式、给江越的空间感），并在第五章等候区协助处理流言。同伴选择是贯穿第三到五章的唯一持久选择结果。

## 功能边界

包含：
- 周予安（班长）和许栀（文体委员）两名同伴 NPC 的 idle 动画与跟随逻辑
- 第三章的同伴选择交互（走近 NPC ≤1.5m 并交互）
- 跟随阶段：与玩家保持 1.5m 间距的路径跟随行为
- 第四章同伴位置差异（周予安停在楼梯入口；许栀退后至角落）
- 第四章步骤 6 同伴联络方老师的差异行为（拨电话 vs 发消息）
- 第五章步骤 3 同伴协助处理流言（周予安主动说「各自去忙吧」）
- 屏幕右下角同伴图标显示
- `companionChoice` 写入 `GameNarrativeState`（一次性，不可更改）

不包含：
- 第六章中同伴的额外关系余波（后续增强，不在首版范围）
- 二周目同伴关系变化
- 与同伴的多轮深度对话（只有选择时的一句反应和必要场景台词）
- 同伴的战斗或冲突行为

## 验收标准

- [ ] 第三章步骤 4：班长和许栀均可独立触发选择，选后 `GameNarrativeState.companionChoice` 正确写入 `.zhouYuAn` 或 `.xuZhi`，且全局仅写入一次（幂等）
- [ ] `companionChoice == .none` 时不允许进入第四章（章节门禁拦截）
- [ ] 同伴跟随阶段：NPC 与玩家保持 ≈1.5m，能绕过教室/走廊障碍物，不穿墙
- [ ] 第四章进入楼梯间后，周予安站楼梯入口、许栀退后角落，行为自动触发，无需玩家操作
- [ ] 第四章步骤 6：周予安拨电话路径方老师 30 秒内到达；许栀发消息路径成人到场更克制，两路均可完成安全交接
- [ ] 第五章步骤 3：周予安在场时主动说「各自去忙吧」，在玩家未操作时自动完成流言处理
- [ ] 屏幕右下角同伴图标在跟随阶段持续显示，进入楼梯间后仍正确更新
- [ ] 存档恢复后同伴状态（位置、跟随模式）与保存前一致，不重新触发选择对话

## 设计约束

- 同伴选择写入 `GameNarrativeState.companionChoice`，不在 `Ch3State` 复制，不允许两处各维护一份
- 同行者不负责评估风险，不直接与江越进行深度对话，只承担联络和空间维持职责
- 选择动作通过一次 `completeStep` 幂等提交，不可被玩家再次修改
- 同伴行为由 `ClassroomCoordinator.update(game:)` 单向映射，不直接持有剧情状态
- SCNNode 动画和路径由 Coordinator 依据 `companionChoice` 和当前章节检查点确定性重建，不进入存档
