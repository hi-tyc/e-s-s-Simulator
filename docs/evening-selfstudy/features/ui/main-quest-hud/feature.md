# F-03 主线任务 HUD

> 状态：final / accepted
> 实现阶段：Phase 0
> 依赖特性：F-01（叙事状态机与章节进度）

## 产品能力描述

用一个始终在场的 HUD 面板向玩家呈现当前主线任务、当前目标和可选操作提示，替代原回合制多指标 HUD。当玩家需要自我定位时，HUD 随时可读；当场景演出收束视角时，HUD 自动退为极简，不干扰叙事节奏。

## 功能边界

**包含：**
- `MainQuestHUD` SwiftUI 视图：主线任务（常驻小字）、当前目标（醒目大字）、引导提示（可选细字）
- 目标切换动画（旧目标淡出、新目标从下方滑入，0.3s easeInOut）
- 紧急状态高亮（`isUrgent == true` 时目标文字变暖橙色）
- 线索便签层：最多叠 5 张，每张出现时有纸张翻动音效，位于 HUD 顶部
- 内心独白组件：屏幕下方 1/4 区域，半透明黑底，手写字体，淡入 0.3s 停留 3s 淡出
- HUD 极简模式：演出收束控制时只保留暂停与字幕入口，主任务和目标退出但不消失为空
- `liquidGlassPanel` 辅助从 ContentView 私有扩展提升为模块共享（使 MainQuestHUD 独立文件可用）

**不包含：**
- 各章具体目标文字的内容决策（由各章步骤逻辑写入 `GameManager`）
- 内心独白文案（由各章状态机决定触发时机和文字）
- 信任值、倒计时、风险评级等原回合制或第四章专用数值显示
- 微游戏 overlay（属于 F-12）
- 辅助设置面板（属于 F-07）

## 验收标准

- [ ] 进入任意章节后 3 秒内 HUD 显示当前目标，字号与颜色符合规格（主任务 11pt/白色 50% 透明、当前目标 14pt semibold）
- [ ] 完成当前目标后 1 秒内新目标出现，动画为旧目标淡出后新目标从下方滑入（0.3s easeInOut）
- [ ] `isUrgent == true` 时目标文字为 `.orange`，`false` 时为 `.white`
- [ ] 演出收束控制期间 HUD 退为极简（仅保留暂停/字幕入口），但不消失为空白或播放器界面
- [ ] 线索便签最多同时叠 5 张，每次新增时播放纸张翻动音效
- [ ] 内心独白组件在触发后淡入 0.3s、停留 3s、淡出；不与当前目标文字重叠
- [ ] 系统 VoiceOver 朗读顺序与视觉顺序一致（主线任务 → 当前目标 → 提示）
- [ ] 系统 Reduce Motion 开启时，目标切换和独白淡入改为即时或 0.2-0.4s 淡入淡出，完成判定不变

## 设计约束

- 任何时刻只显示一项当前目标；`QuestHUDItem.currentGoal` 是单一字符串，不是列表
- `liquidGlassPanel` 样式只能调用统一辅助，不得在 HUD 文件中复制实现
- 内心独白不以阅读速度作为失败条件；与独白同时进行的操作窗口不受独白可见状态影响
- HUD 宽度上限 220pt，固定在屏幕左侧中部（`alignment: .centerLeft`，leading 16pt padding）
- 线索便签文字不得自动泄露声音来源身份，只呈现玩家已通过操作确认的信息
- 不得引入第二套主线状态变量；HUD 只读 `GameManager` 发布的 `quest` 与 `currentHUDItem`
