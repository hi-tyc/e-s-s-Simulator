# F-09 内心独白与线索便签

> 状态：final / accepted
> 实现阶段：Phase 2
> 依赖特性：F-03（主线任务 HUD）

## 产品能力描述

当玩家通过操作或兜底完成章节步骤时，苏念的内心独白以卡片形式短暂浮现在屏幕下方，给玩家一个低调、第一人称的情绪锚点，而不打断主线叙事节奏。同时，已确认的关键线索以便签形式堆叠在 HUD 顶部，让玩家随时感知「我发现了什么」，无需靠记忆管理信息。

## 功能边界

**包含：**
- 第一章六个步骤完成后对应的内心独白文本定义（触发时机 + 内容 + 去重 ID）
- 第一章三张线索便签的内容定义（标题 + 可选详情 + 出现时机）
- 步骤完成 → `presentMonologue` / `appendClueCard` 的调用规则（哪个步骤触发哪条，顺序和去重逻辑）
- 独白计时与 `activePauseReasons` 联动规则（暂停时冻结剩余时间，恢复后继续，不重播）
- 独白 ID 命名约定与防重入规则（同一 ID 的独白不可叠加播放）
- 线索便签 ID 命名约定（格式 `chapter.step.序号`）与上限守护（最多 5 张，超出时静默忽略新增）
- 第三章步骤 1（纸条背面线索）触发独白与便签的内容定义
- 第一章旁白字体要求（手写字体 `.custom("HandwritingFont", size: 15)`，后备系统草体）

**不包含：**
- `InnerMonologueView`、`ClueCardStack`、`ClueCard`、`InnerMonologueItem` 的 View/结构体实现（属于 F-03）
- `GameManager.presentMonologue`、`appendClueCard` 方法实现（属于 F-03）
- 第二章至第六章的独白与便签内容（由对应章节特性分别调用 F-03 接口）
- 林澈 NPC 具体动画和纸条物理事件（属于 F-10）
- 调试面板或独白重播功能

## 验收标准

- [ ] 第一章步骤 1（林澈观察）完成后，内心独白「林澈今天只翻了一页书……」淡入 0.3s、停留 3s、淡出；HUD 顶部出现第一张线索便签「林澈今晚一直看着同一页」
- [ ] 第一章步骤 2（听清声音）完成后，独白「……有人在哭？还是我听错了？」按相同时序播放；声音面板提示消失后独白不再重放
- [ ] 第一章步骤 5（捡起纸条）完成后，便签「匿名求助纸条」出现；纸张翻动音效由 `SpatialAudioManager` 播放，不在 F-09 内自行调用 AVFoundation
- [ ] 三张线索便签累计后，再次触发便签新增事件时不超出 5 张上限，超出时静默忽略
- [ ] 暂停（`activePauseReasons` 非空）期间，正在播放的独白计时冻结；恢复后剩余时间继续，独白不重播
- [ ] 同一独白 ID 在同一章节内二次触发时（例如 fallback 与玩家操作同帧），只播放一次
- [ ] 所有独白文字可被系统 VoiceOver 朗读；VoiceOver 焦点离开独白后，计时继续（不阻塞）
- [ ] 系统 Reduce Motion 开启时，独白淡入改为即时显示，停留时长不变

## 设计约束

- 独白文案是产品叙事的一部分，改动时须保持苏念第一人称语气和口语化风格，不得变成系统提示语
- 独白播放期间不阻止玩家操作；内心独白不是确认对话框
- 便签只呈现玩家通过操作（或 fallback）已确认的信息，不预先泄露声音来源身份
- `presentMonologue` 调用必须从主线步骤完成逻辑中发出，不在 `ClassroomCoordinator` 或 View 层直接调用
- 手写字体如果缺失，必须回退为系统草体（`UIFont.systemFont` 斜体），不能 crash
