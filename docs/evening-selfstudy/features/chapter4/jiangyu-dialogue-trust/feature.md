# F-16 江越对话与信任系统

> 状态：final / accepted
> 实现阶段：Phase 5
> 依赖特性：F-13（第三章同伴选择写入 companionChoice）、F-14（第四章场景底座）、F-10（ChapterDialogue 对话系统扩展，ActiveEvent/EventChoice 扩展为多轮对话）

## 产品能力描述

玩家通过苏念在楼梯间与江越的一系列对话，积累隐性信任值并触发风险信息披露，最终由同行者协助成人接管，完成"让江越知道他不是一个人"的核心叙事目标。信任值对玩家不可见，由回应方式自然积累；披露结果不等于风险评估，成人到场才是真正的安全保证。

## 功能边界

### 包含

- 破冰对话（步骤 2）：三个开场选项，含补救路径
- 倾听阶段（步骤 3）：江越四段独白，每段后玩家 15 秒响应窗口，七种回应类型
- 信任值计算：`DialogueTrustReducer` 纯函数，基础值来自前三章积累
- 追问阶段（步骤 4）：教育便签 + 三种问法选项，输出 `RiskDisclosure`
- 陪伴阶段（步骤 5）：告知成人意愿的对话，写入 `jiangYueWillingToGo`
- 成人交接分流（步骤 6）：根据 `jiangYueActualRisk` 编剧事实决定三种安全路线
- 课间倒计时 HUD（屏幕右上角，极小数字，剩余 2 分钟变暖橙色）
- 教育便签系统：玩家主动关闭，不自动消失

### 不包含

- `jiangYueActualRisk` 的计算逻辑（这是编剧设定的剧情事实，固定为 `.moderate`）
- 安全响应脚本的具体文本（需专业审核后以资源文件接入）
- 方老师到场后的临床处置（由成人负责，学生角色不执行）
- 江越 NPC 的 3D 动画资产制作
- 第五章等候区逻辑

## 验收标准

- [ ] 信任值对玩家不可见：无数字显示、无进度条、无颜色反馈，只通过江越的表情/肩膀/声音体现
- [ ] 教育便签在追问选项出现前展示，且可被玩家主动关闭，不以固定时间自动消失
- [ ] 三种追问方式（`.gentle/.direct/.deferToAdult`）均能推进主线，选 C（交由成人）不出现"没事"式淡化结局
- [ ] `.unknown` 披露状态不被解释为低风险；成人到场前江越不会被单独留下
- [ ] `jiangYueActualRisk == .high/.imminent` 时取消普通课间倒计时，进入紧急响应路线
- [ ] 三种安全路线（`.standardCounseling/.urgentSchoolResponse/.emergencyServices`）由编剧风险事实决定，与信任分无关
- [ ] `safetyRoute` 与 `CounselingEntryMode` 在章节转换前以原子方式持久化，不允许先切场景再补状态
- [ ] 破冰选项 A（防御路径）触发同行者补救，两次机会后自动通过，主线不断
- [ ] 倒计时归零而主线未到步骤 6 时，SceneDirector 自动触发同行者联系方老师
- [ ] 步骤完成后自动存档，读档恢复后信任值、披露状态、同行者选择不丢失不重置

## 设计约束

- `DialogueTrustReducer` 必须是纯函数，结果写回 `GameManager.narrative`，不创建可观察单例
- 安全路线由 `jiangYueActualRisk` 决定，禁止将信任分或披露结果映射为安全路线
- 江越在成人到场前不得被单独留下：即便 `disclosedRisk == .unknown`，同行者也必须留在附近
- `completeStep` 必须幂等：同一步骤只允许提交一次结果，玩家操作与 fallback 同时到达只写入一次
- 安全响应 Beat 进入高危/紧急路线后优先级高于普通剧情 Beat，并取消普通倒计时
- 心理专业审核文本以资源文件接入，不硬编码在状态机或视图中
