# F-19 苏念咨询与支持网络结局

> 状态：final / accepted
> 实现阶段：Phase 6
> 依赖特性：F-01（叙事状态机与章节进度）、F-03（主线任务 HUD）

## 产品能力描述

玩家扮演苏念走进咨询室，选择是否说出自己的事，随后在手绘风支持网络图中看到这一晚建立的人际连接，确认求助资源后以七种结局文字完成情感收束。本特性承接前五章的全部叙事选择，将累积的跨章状态转化为有差异感的终章体验。

## 功能边界

**包含：**
- 苏念走向走廊镜子并进入咨询室（步骤 1-2）
- 咨询对话：4 个主题选项 + 「今天先坐一会儿」选项（步骤 3）
- 支持网络回顾界面：五个节点逐一点亮，可点击查看本局选择痕迹（步骤 4）
- 七种结局文字，按固定优先级由 `EndingSelector` 命中唯一主结局，可叠加自我照顾附注（步骤 5）
- 求助资源卡片：全国热线 12356、紧急联系、学校咨询室；提供 `NSPasteboard` 复制按钮
- `SupportResourceCatalog` 本地配置读取，资源审核日期门禁（Release 超 6 个月失败）

**不包含：**
- 前五章的叙事逻辑和状态写入（由 F-16、F-17、F-18 负责）
- `NarrativeSave` 存档框架（由 F-01 负责）
- 咨询室门前的等候流程和流言事件（由 F-18 负责）
- 心理教育便签的展示（在第五章已完成）
- 二周目额外内容（不在首版范围）

## 验收标准

- [ ] 求助资源提供明确复制按钮，通过 `NSPasteboard` 复制，全国热线正确显示 `12356`
- [ ] 结局文字不出现「你赢了/失败了」等评判语；心理老师不下诊断、不提供万能建议
- [ ] `EndingSelector` 按 §6.4 固定优先级命中唯一主结局；紧急路线、自愿路线、普通路线均可独立触发对应结局
- [ ] 七种主结局均有对应测试场景，`suNianSelfCared == false` 时正确追加自我照顾附注
- [ ] 支持网络图五个节点按 500ms 间隔逐一点亮；点击任意节点展开两行本局痕迹文字
- [ ] 学校资源来自 `SupportResourceCatalog`，资源审核日期超过 6 个月时 Release 构建失败
- [ ] 玩家选择「今天先坐一会儿」时 `suNianSharedSelf` 保持 `false`，结局正确命中「下次也可以」
- [ ] 步骤 4 支持网络图可手动关闭或 10 秒后自动继续；求助资源必须由玩家确认，不可静默跳过
- [ ] 所有步骤可仅用键盘完成；心理老师保密边界脚本在 Release 构建前必须配置审核版本

## 设计约束

- 心理老师台词严格遵循经专业审核的保密边界脚本，未配置审核版本时 Release 构建失败。
- `EndingSelector` 是纯函数，不得引入可观察单例；结局文字体现具体痕迹差异，禁止泛化为相同励志语。
- `SupportResourceCatalog` 读取本地配置，热线号码、服务时间、学校联系方式不得散落硬编码在 View 中。
- 保密边界脚本内容：谈话通常被尊重保护；涉及苏念或他人面临严重即时安全风险时老师会联系能保护她的人并提前告知。
- 进入本特性时 `GameNarrativeState.supportHandedOff` 必须为 `true`，否则属于非法章节转换，由 F-01 门禁拦截。
