# F-05 序章 Beat 状态机

> 状态：final / accepted
> 实现阶段：Phase 1
> 依赖特性：F-01（叙事状态机与章节进度）、F-02（SceneDirector 节拍系统）、F-04（叙事相机模式与场景呈现）

## 产品能力描述

F-05 实现序章《铃响之前》的 9 段演出节拍调度，引导玩家在约 7.5–9 分钟内通过 75% 场景演出 / 25% 轻操作完成视角、移动、交互和辅助设置四类基础操作教学。每段操作最多等待 12 秒后由苏念自然完成，无任何失败判定。序章结束时，HUD 无缝切换为第一章目标，不出现加载黑屏。

## 功能边界

**包含：**
- `PrologueBeatID`（9 段具名节拍）的注册、调度与幂等完成
- 每段节拍对应的输入限制模式（`PrologueInputMode`）
- 12 秒（教学段）或 10 秒（观察/呼吸段）自动兜底路径
- `PrologueState` 6 个教学完成标记的写入与持久化
- 暂停/恢复与稳定存档检查点（每段结束后建立）
- 已完成序章的新档"直接从第一章开始"入口

**不包含：**
- 校门/走廊新场景的 3D 构建与入场动画（属于 F-06）
- 辅助设置面板的 UI 实现（属于 F-07）
- 第一章任何叙事步骤逻辑
- 关系分、风险分或结局分支（序章不产生任何跨章叙事数值）

## 验收标准

- [ ] 首次进入后 3 秒内出现画面或字幕，不出现黑屏等待
- [ ] 任一教学节点不操作时，最多 12 秒完成并进入下一段，不弹出"操作失败"
- [ ] 视角、移动、交互、暂停/辅助四类操作各有一次自然情境提示，提示不以考试题形式出现
- [ ] 任何教学操作没有失败判定、扣分、重来或"错误答案"
- [ ] 演出暂停后字幕、音频、自动兜底计时和镜头进度一致冻结；恢复后从剩余时间继续，不跳段
- [ ] `settleBreath` 节拍完成时 `GameNarrativeState.suNianSelfCared` 保持初始值，不被序章写入
- [ ] 序章结束时玩家处于第一章第三排座位初始镜头、初始 HUD 和初始环境音，不出现加载黑屏
- [ ] 已完成序章（`prologueCompleted == true`）的新档，主菜单提供"直接从第一章开始"选项
- [ ] 开启方向字幕、减少动态效果、键盘替代输入后，序章可完整通关
- [ ] 演出中不把同学的隐私、心理状态或风险当作可供围观的谜题展示

## 设计约束

- 演出不得使用全屏 MP4 或播放器进度条；所有节拍由同一个 SceneKit 场景驱动，与正式关卡一致
- `completePrologueBeat(_:flags:)` 必须幂等；玩家操作、自动兜底和演出自然完成三条路径调用同一接口
- 序章不得为增加可玩性塞入收集物、跑图或对错选择；轻操作只服务于叙事动机
- `settleBreath` 节拍明确禁止写入 `GameNarrativeState.suNianSelfCared`，该字段仅由第一章步骤 3 写入
- 不提供第一次游玩的"一键跳过序章"；所有节拍可自动完成，但不可整体跳过
- 序章结束到第一章开始的 HUD 切换必须在同一帧内完成（铃声余韵中），不依赖异步加载
