# F-06 校门/走廊新场景与入场演出

> 状态：final / accepted
> 实现阶段：Phase 1
> 依赖特性：F-04（叙事相机模式与场景呈现）、F-05（序章 Beat 状态机）

## 产品能力描述

为序章《铃响之前》提供两个全新的 3D 场景根节点——校门外和教学楼走廊——以及由 SceneDirector 驱动的受控入场演出（段落 0：0:00-0:55）和视角教学（段落 1：0:55-1:35），让玩家在进入第三排座位之前先建立对世界的空间感知。

## 功能边界

包含：
- 校门外场景根节点（`gateExterior`）：苏念从校门进入教学楼的单向过渡演出
- 教学楼走廊场景根节点（`corridor`）：走廊尽头方老师与班长的演出，以及玩家的第一次视角转动教学
- 段落 0（`gateArrival` Beat）：受控入场演出，玩家只能暂停/设置，苏念自动走入楼内
- 段落 1（`lookDownHall` Beat）：演出交还视角，教学"转动视角"，12 秒未完成则苏念自然转头兜底
- 从走廊到第三排座位的衔接（段落 2 `returnToSeat` 在走廊结束、教室开始的边界触发，属本特性负责的入口）

不包含：
- 段落 2 之后的所有序章 Beat（属 F-05 序章 Beat 状态机的内部逻辑）
- 走廊在第二章的再次使用（镜像空间，属 F-11）
- 校门外或走廊场景的第三人称自由漫游（属 F-13）
- 辅助设置面板本身（属 F-07），本特性只调用其受限入口

## 验收标准

- [ ] 首次进入游戏后 3 秒内，校门外场景出现画面或字幕，不出现黑屏等待
- [ ] 段落 0 演出期间，玩家只能执行暂停/设置操作，移动、互动和剧情选择均被禁止
- [ ] 段落 0 演出约 55 秒结束后，无需任何玩家操作，镜头自动衔接到走廊第一人称视角
- [ ] 段落 1 开始后，HUD 显示"看向走廊尽头"目标和"移动鼠标或使用视角键"提示
- [ ] 玩家将视角转到走廊尽头目标区域并短暂停留后，聚焦反馈立即触发，目标标记为完成
- [ ] 玩家在 12 秒内未完成视角转动时，苏念自然转头兜底，HUD 写"你注意到了走廊里的动静"，不弹出"操作失败"
- [ ] 暂停（含应用失焦、系统休眠）期间，受控演出和自动兜底计时同步冻结；恢复后从冻结点继续，不跳段
- [ ] 每段 Beat 完成后创建稳定检查点；从任意检查点读档可确定性重建校门/走廊场景状态，不出现半完成演出帧
- [ ] 开启方向字幕时，环境声（球场收场声、楼道脚步、广播试音）以"[方向：声音类型]"格式呈现；字幕不提前暴露林澈异常

## 设计约束

- 演出不使用全屏 MP4 或播放器控件；校门外与走廊场景必须是同一 SceneKit 世界中的场景根节点，由 SceneDirector 驱动 NPC 路径、相机锚点和环境音
- 段落 0 期间 HUD 退为极简（仅暂停/字幕按钮），但不消失为播放器界面
- 苏念旁白在段落 0 和段落 1 中出现，内容固定，不可随机变体（首版范围）
- 校门外场景使用偏暖室外光，走廊使用中性教室灯，禁止恐怖化滤镜
- 镜头不在任何同学面部停留过久，不提前暗示林澈异常
- `gateArrival` 和 `lookDownHall` Beat 的已完成 ID 写入 `MainQuestProgress.completedBeatIDs`，读档后不得重复执行
- 场景根节点按章按需激活，任一时刻只激活当前节点及转场所需的相邻根节点；校门外节点在进入走廊后即可卸载
